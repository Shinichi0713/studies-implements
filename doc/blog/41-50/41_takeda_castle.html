    秀吉の弟である秀長は、秀吉の中国攻めの際には、羽柴軍の副将格として後方統治や補給に当たることが多かったようです。 しかし、そんな秀長が一軍を率いて攻略をした戦いがあります。 そんな戦いの一つが竹田城の攻略戦です。

    本日テーマ：

    本日は秀長が一軍を指揮した戦いである竹田城について解説していきます。

    竹田城攻めの概要

    羽柴秀長が行った竹田城攻めは、織田信長の「中国攻め（中国征伐）」の一環として行われた但馬平定作戦の一部です。以下に、中国攻めとの関係も含めて概要を整理します。

    1. 背景：中国攻めと竹田城の重要性

    • 天正5年（1577年）、織田信長は毛利輝元の勢力圏（山陽・山陰）を攻めるため、羽柴秀吉に中国攻めを命じますWikipedia。
    • 但馬国（現在の兵庫県北部）は、山名氏や太田垣氏ら国衆が支配する地域で、その中でも竹田城は、生野銀山を押さえる軍事・経済の要衝として重要視されていましたサライ.jp。
    • 生野銀山は信長政権にとっても重要な収入源であり、毛利方に傾く但馬勢力を切り崩し、銀山を確保することが中国攻めの重要な戦略目標でした。

    2. 羽柴秀長の但馬侵攻と竹田城攻略（天正5年・1577年）

    秀長の役割

    • 秀吉は播磨平定を進めつつ、弟・羽柴秀長（小一郎）を先鋒として但馬侵攻を担当させますサライ.jp。
    • これは、中国攻め全体の中で、但馬方面の平定と生野銀山の確保を任せるという位置づけでした。

    侵攻ルートと前哨戦

    • 天正5年（1577年）11月、秀長軍は真弓峠を越えて但馬へ侵攻しますサライ.jp。
    • まず岩洲城（いわすじょう）を攻略し、その後、竹田城を本格的に攻めますサライ.jp。

    竹田城攻めの様子

    • 戦いは3日間にわたって続いたと伝えられ、最終的に城主・太田垣輝延が降伏し、竹田城は陥落しましたサライ.jp。

    3. 中国攻めの一環としての位置づけ

    • この竹田城攻略は、秀吉の中国攻めにおける「但馬平定」の重要な一戦でした。
    • 竹田城を落とすことで、
      • 生野銀山の支配権を確保し、
      • 毛利方に与する但馬国衆（太田垣氏ら）の抵抗拠点を奪い、
      • 山陰方面への進軍路と補給路を安定させる という戦略的意義がありましたサライ.jp。

    より詳細な背景

    竹田城攻めが開始された当時について状況の説明を行います。

    1. 中国攻めの開始と播磨平定（天正5年・1577年10月〜）

    • 天正5年（1577年）10月、羽柴秀吉は北陸戦線から離れ、織田信長から中国攻め（毛利攻め）を命じられ、播磨に入りましたWikipedia。
    • 秀吉は黒田孝高から提供された姫路山城を本拠とし、赤松則房ら多くの国人衆を調略で降伏させ、西播磨全域をほぼ支配下に置きましたWikipedia。
    • 11月〜12月にかけては、福原城や上月城（第一次上月城の戦い） といった毛利方の拠点を攻略し、播磨平定を進めましたWikipedia。

    この時点で、秀吉は播磨をほぼ掌握し、毛利氏との前線を固めつつ、次の戦略として但馬・因幡方面への進出を視野に入れていました。 (因みにこの後別所氏や荒木村重の離反により播磨の情勢はみるみる悪化していくことになりますが)

    2. 但馬侵攻の開始と竹田城攻めの位置づけ

    • 中国攻めの記事によれば、但馬侵攻も天正5年（1577年）の同時期に行われ、岩洲城や竹田城を攻略し、羽柴秀長を城代として配置したとされていますWikipedia。
    • ただし、『信長公記』によれば、信長の命令はあくまで「播磨攻略」であり、但馬侵攻は秀吉の独断であったと記されていますWikipedia。
    • 竹田城攻めは、秀吉が播磨平定を進める中で、自らの判断で但馬方面にも戦線を広げた一環として始まりました。

    3. 竹田城攻め開始当時の具体的な状況

    但馬側の状況

    • 但馬は山名氏や太田垣氏ら国衆が支配していましたが、毛利氏の影響力が強まり、織田方から離反する動きが出ていましたサライ.jp。
    • 竹田城は、生野銀山を押さえる軍事・経済の要衝であり、毛利方に与する太田垣輝延が城主でしたサライ.jp。

    秀吉・秀長側の動き

    • 秀吉は播磨平定をほぼ終えた後、弟・羽柴秀長を先鋒として但馬侵攻を命じますサライ.jp。
    • 秀長軍は真弓峠を越えて但馬に入り、まず岩洲城を攻略し、その後竹田城を攻撃対象としましたサライ.jp。

    4. 竹田城立地

    竹田城は兵庫県の但馬地方の中央付近に位置します。 これは現在の地図ベースの竹田城の位置です。

    竹田城は山の峰に建てられた城で典型的な山城です。 太田垣氏が140年の支配をしたとなっているのですが、恐らくここまで戦火に見舞われることがなかったと思われます。 実質、竹田城始まって以来初めての戦いだったのでは、と思います。

    秀長の軍は播磨の姫路を発ち、北上して真弓峠を越えて但馬に入ったと考えられます。

    軍勢の比較

    秀長軍と太田垣氏（竹田城側）の軍勢を比較するにあたっては、秀長軍については但馬侵攻全体の兵力が分かっている一方、太田垣氏側の具体的な兵力数は一次史料ではほとんど確認できないという制約があります。そのため、史料に基づく数字と、城の規模・籠城戦の様子からの推定を組み合わせて比較します。

    1. 秀長軍の軍勢

    但馬侵攻全体の兵力

    • 秀長の但馬侵攻については、秀長軍は約6,500の兵力を有していたとする記述があります大屋山遊会（藤堂高虎関連記事）。
    • これは、但馬平定全体（岩洲城・竹田城など複数の城攻め）に投入された兵力と理解するのが妥当です。

    竹田城攻めに投入された兵力

    • 竹田城攻めは、真弓峠越えで但馬に入った秀長軍が、まず岩洲城を落とし、次いで竹田城を攻めたとされていますサライ.jp。
    • 岩洲城攻略にも兵力を割いているため、竹田城攻めに直接投入された兵力は、6,500のうちの一部と考えられます。
    • ただし、竹田城は生野銀山を管轄する最重要拠点であり、秀長隊の第一目標とされたことから、主力部隊が集中したと見るのが自然ですWikipedia（竹田城）。

    まとめると：

    • 但馬侵攻全体：約6,500（秀長軍の総兵力）
    • 竹田城攻め：その主力が投入されたと推定されるが、具体的な数字は史料に明記されていない

    2. 太田垣氏（竹田城側）の軍勢

    史料上の制約

    • 太田垣輝延が率いた竹田城側の兵力については、一次史料で具体的な数字がほとんど確認できません。
    • ただし、竹田城は山城で非常に堅固であり、籠城戦を前提とした防衛が行われたとされています。

    城の規模と防衛力からの推定

    • 竹田城は、標高約350mの山頂に築かれた山城で、石垣や曲輪が広がる大規模な城郭です。
    • 戦国時代の山城としては、数百〜1,000人規模の兵が籠城できると推定されることが多いです。
    • 太田垣氏は但馬の有力国衆で、山名氏の重臣として一定の兵力を動員できたと考えられますが、織田・羽柴軍に比べれば兵力は劣勢だったと見るのが一般的です。

    まとめると：

    • 太田垣氏側の兵力：数百〜1,000人程度の籠城兵と推定されるが、具体的な数字は不明
    • 防衛面では、山城の堅固さと籠城戦で対抗した

    3. 両軍の比較（兵力・戦力・戦い方）

    兵力規模の比較

    • 秀長軍（但馬侵攻全体）：約6,500（複数の城攻めに投入）
    • 太田垣氏（竹田城側）：数百〜1,000人程度と推定（籠城兵）

    → 兵力面では秀長軍が圧倒的に優勢だったと考えられます。

    戦い方の比較

    • 秀長軍：
      • 真弓峠越えで但馬に侵攻し、岩洲城を落とした後、竹田城を強襲。
      • 鉄砲を多用した積極的な攻城戦を展開。
    • 太田垣氏：
      • 山城の堅固さを活かし、籠城戦で時間を稼ぎつつ抵抗。
      • 3日間の戦闘の末、降伏・退去したと伝えられています古城の歴史 竹田城。

    戦闘の経過

    竹田城攻め（天正5年・1577年）の開始から終結までの展開については、ざっと以下のようなものです。

    1. 竹田城攻めの開始（秀長軍の進軍と包囲）

    • 秀吉は播磨平定を進めた後、弟・羽柴秀長を先鋒として但馬侵攻を開始させますサライ.jp。
    • 秀長軍は真弓峠を越えて但馬に入り、まず岩洲城（いわすじょう）を攻略しましたサライ.jp。
    • 岩洲城を落とした後、秀長軍は竹田城へ進軍しますサライ.jp。
    • 竹田城は標高約350mの山城で天然の要害であり、太田垣輝延は籠城戦で対抗する構えでした。
    • 秀長軍は城の周囲を包囲し、攻城戦を開始します。
      • 史料によれば、鉄砲300挺を投入するなど、強力な火力で攻撃したと伝えられていますサライ.jp。

    2. 戦闘の展開（3日間の攻防）

    なんと秀長は攻めづらい山城を3日で攻略してしまいました。

    • 竹田城では3日間にわたる激しい攻防戦が繰り広げられたとされていますサライ.jp。
    • 秀長軍は鉄砲隊による射撃や、山城への突入を繰り返し、城兵を圧迫しました。
    • 一方、太田垣輝延側は山城の地形を活かして防衛し、籠城戦で時間を稼ぎつつ抵抗しましたが、兵力・装備の面で秀長軍に劣勢だったと考えられます。

    戦力や装備が良かったとは言え、効率よく竹田城を攻めたことは間違いないと思います。 鉄砲の射撃を巧みに使った攻城戦だったと推定出来ます。

    3. 太田垣輝延の降伏と竹田城の陥落

    • 3日間の戦闘の末、城主・太田垣輝延は降伏し、竹田城から退去したと伝えられています古城の歴史 竹田城。
    • これにより、竹田城は秀長軍の手に落ち、但馬平定の重要な一歩となりました。

    4. 戦後の展開（秀長の城代就任と但馬支配）

    竹田城を攻略することで但馬攻略の重要な橋頭保を確保したことになります。 そして、秀長はこの重要な拠点の城代として支配を任されることになります。

    • 竹田城陥落後、秀長は城代として竹田城に入り、但馬支配の拠点としましたサライ.jp。
    • 秀長は城の普請（補修・拡張）や道路整備、生野銀山の経営にも関わり、実戦指揮官としてだけでなく、行政・経済面でも能力を発揮したと評価されていますサライ.jp。
    • その後も但馬では旧勢力の反発がありましたが、天正8年（1580年）に秀長が再び但馬へ出陣し、完全な平定を実現しますサライ.jp。

    秀長はこの後但馬の攻略を進め、但馬の2郡の統治を任されることになります。

    総括

    秀長は、竹田城攻めにおいて、

    • 中国攻めの但馬方面における実戦指揮官として前線を切り開き、
    • 火力を集中させた積極的な攻城戦で3日という短期間に堅城を落とし、
    • 生野銀山の確保と但馬平定の基盤を築くという戦略的役割を果たし、
    • 戦後は城代として統治・経営面でも能力を発揮しました。

    この戦いは、秀長がそれまでの秀吉の補佐役としての仕事が多かったですが、軍事・行政の両面で実力を示した転機の一つとなりました。 そういう意味では、その後の豊臣政権における補佐役としての地位を確立するうえで重要な役割を果たしたと言えます。
