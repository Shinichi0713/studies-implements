目次

    子供は体が大きくなるので当たり前ですが、数カ月経過によって靴の買い替えが必要となります。 靴を買い替えしようとしているときに、ふと、靴って発育にどんな影響があるんだっけ？と感じました。 そこで靴と発育の関係性について調べてみました。

    従来研究

    子供の靴と足の発育・運動能力に関する研究は、国内外で多数存在します。

    主に以下のような観点で研究が行われています。

    1. 靴が足の発育・歩行に与える影響に関する研究

    • 英語圏の総説論文では、子どもの靴が足の健全な成長と歩行（gait）の発達に重要な役割を果たすことが指摘されていますPMC。
    • 同じ論文では、裸足に近い柔軟な靴が、自然な足の成長を促すことや、不適切なサイズ・硬い靴が足の変形や歩行の乱れにつながる可能性が議論されていますPMC。

    2. 日本国内の「足育」・靴教育に関する研究・実践

    • 日本では、幼稚園・保育園などでの「足育」実践が行われており、足の計測や靴の選び方・履き方教育を通じて、運動遊びへの意欲や健康な体への関心を高める取り組みが報告されていますJASPE 足育指導資料。
    • その中で、「靴のサイズが合っているか不安」という保護者の声が多く、正しい靴選び・履き方の継続的な啓発が必要という課題も示されていますJASPE 足育指導資料。

    3. 靴設計と運動能力に関する研究

    • 日本靴医学会などでは、子どもの運動能力と靴設計の関係をテーマとした研究が発表されていますPR TIMES。
    • こうした研究では、成長段階にある足の動きや、走る・止まる・切り返すといった日常動作を支える靴の機能が重視されていますPR TIMES。

    4. メーカーによる足の発育を考慮した靴開発

    • ムーンスターなど、長年子ども靴を手がけるメーカーは、整形外科医と共同で子どもの足の成長を考えた機能性ベビー・キッズシューズを開発しており、その設計思想が公開されていますMoonStar。
    • こうした製品開発の背景には、子どもの足の骨が軟骨が多く、かかとが小さくつま先が広い「扇型」であるといった、足の発育段階に基づく研究・知見が反映されていますMoonStar。

    5. 裸足・ベアフットシューズに関する研究

    • 海外の研究や専門家の見解では、「裸足が最良」であり、やむを得ず靴を履く場合は、できるだけ裸足に近い柔軟な靴が望ましいとされていますAPMA。
    • ベアフットシューズ（barefoot shoes）のメーカーも、強い足・良いバランス・自然な歩行を促すことを目的に、医学的・生体力学的な知見を基に設計していると説明していますFroddo。

    研究から考察されること

    ご質問の2点について、既存研究を総合すると、概ね次のような方向性が導かれます。

    1. 正しい歩行を起因とする運動能力への影響

    総論として導出されること

    • 柔軟で足にフィットする靴（あるいは裸足に近い状態）は、歩行・走行の質を高め、運動能力の向上につながる
      という方向性が、複数の研究で支持されています。

    具体的な知見

    • 総説論文では、子どもの靴は足の健全な成長と歩行（gait）の発達に重要な役割を果たすとされ、
      硬すぎる・重すぎる靴は、自然な足の動きや地面からの感覚入力（センサリー入力）を妨げる可能性が指摘されていますPMC。
    • 一方で、柔軟で薄いソールの靴やベアフットシューズは、足指の動きや足裏の感覚を保ち、バランス能力や接地の安定性を高めると考えられていますFroddo。
    • 日本国内の「足育」実践でも、正しい靴選び・履き方の指導により、運動遊びへの意欲や運動パフォーマンスの向上が報告されていますJASPE 足育指導資料。

    まとめ（運動能力）

    • 靴の硬さ・重さ・ソールの厚さが、歩行の安定性・接地感覚・転倒リスクに影響し、
      結果として走る・止まる・切り返すといった運動能力に差が出る、というのが研究の共通した見方です。

    2. 足の骨格自体への影響

    総論として導出されること

    • 不適切なサイズ・硬い・先細りの靴は、成長期の足の骨格変形リスクを高める
      という点で、多くの研究・臨床的知見が一致しています。

    具体的な知見

    • 子どもの足は6〜7歳頃までは軟骨が多く、骨の成長が未完成であるため、
      大きすぎる靴は巻き爪や親指の変形、小さすぎる靴は外反母趾のリスクを高めるとされていますJASPE 足育指導資料。
    • 海外の研究・臨床報告でも、不適切な靴が足の変形（扁平足・外反母趾・ハンマートゥなど）の一因になりうることが示されていますPMC。
    • 一方で、裸足や柔軟な靴は、足の筋肉・靭帯を自然に使わせ、アーチ形成や足の形の健全な発達を促すと考えられており、
      米国足病医学会（APMA）も「裸足が最良」とし、やむを得ず靴を履く場合は軽く柔軟な靴を推奨していますAPMA。

    まとめ（骨格）

    • 成長期の足は形が変わりやすく、靴の圧迫や不適切な支持が骨格の歪みにつながりやすい。
    • したがって、足の形に合ったサイズで、つま先に余裕があり、かかとをしっかり支える靴が、
      骨格の健全な発育を守るうえで重要、というのが総合的な結論です。

    総合的な導出

    研究結果を総論すると、次のように整理できます。

    1. 靴は「足の保護」と「自然な発育」のバランスを取るべき

      • 外出時には靴が必要だが、できるだけ裸足に近い状態を保つことが望ましい。

    2. 歩行・運動能力

      • 柔軟で薄底の靴は、接地感覚・バランス・歩行の安定性を高め、結果として運動能力の向上につながる。

    3. 骨格・足の形

      • 不適切な靴は足の変形リスクを高める一方、
        適切なサイズと柔軟性を持つ靴は、筋肉・靭帯・骨のバランスの良い発達を支える。

    4. 実践的な示唆

      • サイズの合った、つま先に余裕があり、かかとを支え、ソールが柔らかい靴を選ぶことが、
        子どもの足の発育と運動能力の両面で重要、というのが研究の総合的なメッセージです。

    靴の選定ポイント

    「運動能力への影響」と「骨格への影響」の両面から、プラス（良い影響）と考えられる靴の選定ポイントを整理すると、次のようになります。

    1. サイズ（長さ・幅）

    運動能力へのプラス

    • つま先に約1〜1.5cm程度の余裕がある靴は、
      歩行・走行時に指がしっかり使え、蹴り出しが安定しやすくなります。
    • 幅が適度に広く、足指が自由に動かせることで、
      バランスや接地の微調整がしやすくなり、転倒リスクの低減にもつながります。

    骨格へのプラス

    • 成長期の足は軟骨が多く、圧迫されると変形しやすいため、
      つま先に余裕がある靴は、外反母趾・巻き爪・ハンマートゥなどのリスクを下げると考えられますJASPE 足育指導資料。
    • 幅が狭すぎないことで、足の横幅の成長を妨げず、扇型の自然な足形を保ちやすいです。

    2. ソールの硬さ・厚さ

    運動能力へのプラス

    • 薄く柔軟なソールは、地面からの感覚を足裏に伝えやすく、
      歩行・走行時のバランス感覚や接地の安定性を高めますPMC。
    • ソールが適度にしなることで、足指・足裏の筋肉を自然に使うため、
      結果として運動能力の向上につながる、という研究の方向性がありますFroddo。

    骨格へのプラス

    • 硬すぎるソールは、足のアーチ形成や筋肉の発達を妨げる可能性がありますが、
      柔軟なソールは、足のアーチを支える筋肉・靭帯を自然に鍛え、健全なアーチ形成を促すと考えられていますAPMA。
    • 厚すぎるソールは足の動きを制限しがちですが、薄くしなやかなソールは足の自然な動きを妨げにくいため、
      骨格のバランスの良い発達を支えるとされています。

    3. つま先形状（トゥボックス）

    運動能力へのプラス

    • つま先が広く、扇型に近い形状の靴は、
      歩行・走行時に足指がしっかり開き、蹴り出し・バランス調整がしやすいです。
    • 指が自由に動かせることで、転倒予防や運動時の安定性向上につながります。

    骨格へのプラス

    • 子どもの足は**かかとが小さく、つま先が広い「扇型」**であるため、
      つま先にゆとりがある靴は、指の変形や圧迫による骨格の歪みを防ぐのに有効ですMoonStar。
    • 先細りの靴は外反母趾やハンマートゥのリスクを高めるとされており、
      逆に広いつま先は、自然な足の形を保つ方向に働きます。

    4. かかと部分（カウンター）のサポート

    運動能力へのプラス

    • かかとをしっかり包み込む構造の靴は、
      歩行・走行時のかかとの安定性を高め、ブレを減らすことで、
      運動パフォーマンスの向上や転倒・ケガの予防に寄与しますPR TIMES。

    骨格へのプラス

    • 成長期の足はかかとが小さく、柔らかいため、
      かかとをしっかり支える構造は、かかとの骨の位置を安定させ、O脚・X脚のリスクを減らすのに役立つとされていますMoonStar。
    • かかとがぐらつく靴は、足全体のアライメント（姿勢）の乱れにつながりやすいため、
      しっかりしたカウンターは骨格の安定性を高める方向に働きます。

    5. 靴の重さ・通気性

    運動能力へのプラス

    • 軽量で通気性の良い素材の靴は、
      子どもが長時間動きやすく、疲れにくいため、
      結果として運動量の増加や運動能力の維持・向上につながります。

    骨格へのプラス

    • 重い靴は歩行時の負担を増やし、姿勢の乱れにつながる可能性がありますが、
      軽量な靴は足・膝・腰への負担を減らし、骨格の健全な発育を支えると考えられます。
    • 通気性が良いと蒸れによる皮膚トラブルや足の不快感を減らし、正しい歩行を維持しやすくするため、
      間接的に骨格への悪影響を防ぐ効果も期待できます。

    6. まとめ：プラス傾向として導出される選定ポイント

    研究結果を総合すると、運動能力と骨格の両面でプラスと考えられる靴の特徴は、次のようにまとめられます。

    • サイズ：つま先に約1〜1.5cmの余裕があり、幅も適度に広い
    • ソール：薄く柔軟で、足の自然な動きを妨げない
    • つま先形状：扇型に近く、指が自由に動かせる
    • かかと：しっかり包み込んで安定させる
    • 重さ・通気性：軽量で通気性が良く、長時間履いても疲れにくい

    これらを満たす靴は、

    • 運動能力面では歩行・走行の安定性、バランス感覚、転倒予防に、
    • 骨格面では足の変形リスクの低減と、筋肉・靭帯・骨のバランスの良い発達に、
      プラスの影響を与えると考えられます。

    試着時のポイント

    最後に実際選定に試着するだけでは見落としづいらいポイントがあると思います。 以下、試着で見落としがちなポイントを整理します。

    1. サイズの「本当の余裕」が分かりづらい

    よくある誤解

    • つま先を押して「指が少し当たる」＝「ちょうどいい」と判断してしまう。
    • 実際には、歩行時の蹴り出しで足が前に滑るため、
      静止時の「ちょうど」は、動くと「きつい」 になりがちです。

    見分けづらいポイント

    • 歩いたときの前滑り
      静止時は余裕があっても、歩くと靴の中で足が前に移動し、
      つま先が当たるようになることがあります。
    • 靴紐・マジックテープの締め具合
      緩いと前滑りしやすく、きつく締めすぎると血流を妨げるため、
      「適度な締め具合」が分かりづらいです。

    対策

    • 試着時は必ず歩かせる・走らせる。
    • つま先を押すだけでなく、靴の中で足がどれだけ前後に動くかを確認する。

    2. つま先の「形」と「動きやすさ」が分かりづらい

    よくある誤解

    • 見た目が「かわいい」「細身」な靴を選びがちですが、
      実際にはつま先が狭く、指が圧迫されていることがあります。

    見分けづらいポイント

    • 指が自由に動くかどうか
      靴を履いたまま、足指で「グー・パー」ができるか確認します。
      できない場合は、指の動きが制限されている可能性があります。
    • 靴底の曲がる位置
      子どもの足はかかとから3分の2くらいの位置で曲がるのが自然ですMoonStar。
      靴底が硬く、つま先寄りでしか曲がらない場合は、歩行時の負担が大きくなります。

    対策

    • 靴を履いたまま足指を動かす。
    • 靴を曲げて、曲がる位置が足の自然な曲がり位置と一致するかを確認する。

    3. かかとの「安定感」が分かりづらい

    よくある誤解

    • サイズが合っていれば、かかとも安定していると思いがちですが、
      実際にはかかとが靴の中で上下に動く（浮く） ことがあります。

    見分けづらいポイント

    • かかとが浮いていないか
      歩行時に、かかとが靴から浮いて「パタパタ」と音がする場合は、
      かかとのホールドが不十分です。
    • 靴紐・マジックテープの位置
      かかとをしっかりホールドするためには、甲の部分をしっかり締める必要がありますが、
      子どもは自分でうまく締められないことが多く、試着時も確認しづらいです。

    対策

    • 試着時はかかとをトントンと床に当ててから締める。
    • 歩かせて、かかとが浮いていないか・音がしないかを確認する。

    4. ソールの「硬さ・しなり」が分かりづらい

    よくある誤解

    • 靴底が厚く硬いと「丈夫で長持ちしそう」と感じがちですが、
      研究では柔軟なソールの方が歩行・運動能力に良い影響があるとされていますPMC。

    見分けづらいポイント

    • 靴を手で曲げたときの硬さ
      大人が手で曲げて「硬いな」と感じる靴は、
      子どもの足にとってはさらに硬く感じられ、歩行の負担になることがあります。
    • 実際の歩行時の感覚
      子どもは「硬い」「歩きづらい」と明確に言えないことが多く、
      保護者が歩き方のぎこちなさを見逃しがちです。

    対策

    • 試着時に手で靴底を曲げてみる。
    • 子どもに走ってみる・ジャンプしてみるなど、動きの様子を観察する。

    5. 左右差・成長スピードが分かりづらい

    よくある誤解

    • 「左右同じサイズだから大丈夫」と思いがちですが、
      実際には左右で足のサイズが異なることがあります。

    見分けづらいポイント

    • 左右の足の長さ・幅の差
      成長のスピードが左右で異なることもあり、
      片方だけきつい・緩いということがあります。
    • 成長のスピード
      3〜4ヶ月で1サイズ以上大きくなる子もいれば、
      1年近くサイズが変わらない子もいますYouTube 解説動画。
      試着時点では「ちょうどいい」でも、すぐに小さくなる可能性があります。

    対策

    • 左右両方の足を必ず計測・試着する。
    • 3〜4ヶ月ごとにサイズチェックを行う習慣をつける。
