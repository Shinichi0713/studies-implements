
強化学習のコードを作っていると、行動価値関数(※1)の更新式がなんでこれ？ってなりました。
強化学習はフィジカルAIで必要となる環境で行動して学ぶという機能を実現する上で必須の技術です。
強化学習のAIは、今でとりえるベストな行動を選択していきます。このベストな行動を求めるために必要となるのが行動価値関数の更新式です。
そこで行動価値関数の更新式の原理となっているマルコフチェインからMDPの導出→行動価値関数の更新式の導出を行っていきます。

※1 行動価値関数：とある状況で行動を行った場合の将来の価値を示す行動の指標です。

__今回説明の意味:__

現在AIの環境における学習で使われる強化学習のベースは行動価値関数の更新に依存しています。
この原理が分かっていることで、より発展的な強化学習の知見につながっていきます。

## マルコフチェインとは何やねん

強化学習の基礎となる「マルコフチェイン（マルコフ連鎖）」について、順を追って説明します。

### 1. マルコフチェインとは何か

マルコフチェイン（Markov chain）は、**確率過程**の一種で、次のような性質を持ちます。

- 時間とともに状態が変化していく（例：時刻 0, 1, 2, … で状態が変わる）
- ある時刻の状態が決まると、**その次の状態の確率分布は、現在の状態だけに依存**し、それ以前の履歴には依存しない

この性質を「**マルコフ性（Markov property）**」と呼びます。

### 2. 形式的な定義

マルコフチェインは、通常、次の要素で定義されます。

- **状態空間（state space）**  
  取りうる状態の集合 $${ S = \{s_1, s_2, \dots\} }$$
- **遷移確率（transition probability）**  
  ある状態 $${ s }$$ から別の状態 $${ s' }$$ へ移る確率  
  $${ P(s' \mid s) = \Pr(X_{t+1} = s' \mid X_t = s) }$$
- **初期分布（initial distribution）**  
  時刻 0 での状態の確率分布 $${ \Pr(X_0 = s) }$$

このとき、過程全体の確率は
$${ \Pr(X_0, X_1, \dots, X_T) = \Pr(X_0) \prod_{t=0}^{T-1} P(X_{t+1} \mid X_t) }$$
と表せます。これが「過去に依存しない」というマルコフ性の数式的な表現です。

### 3. マルコフチェインの例

__3.1 単純な天気モデル__

- 状態：$${ S = \{\text{晴れ}, \text{雨}\} }$$
- 遷移確率の例：
  - 晴れ → 晴れ：0.7
  - 晴れ → 雨：0.3
  - 雨 → 晴れ：0.4
  - 雨 → 雨：0.6

「明日の天気の確率は、今日の天気だけに依存し、昨日以前の天気には依存しない」と仮定するなら、これはマルコフチェインです。

__3.2 ランダムウォーク__

- 状態：整数 $${ \dots, -2, -1, 0, 1, 2, \dots }$$
- 遷移：各ステップで +1 か -1 に等確率で移動

これも「次の位置は現在の位置だけに依存」するのでマルコフチェインです。

### 4. マルコフチェインの重要な性質

__4.1 既約性（irreducibility）__

どの状態からでも、有限ステップで他のどの状態にも到達できるとき、そのマルコフチェインは**既約**であるといいます。  
強化学習では、エージェントが環境のあらゆる状態を経験できることが望ましいので、既約性は重要な概念です。

__4.2 周期性（periodicity）__

ある状態に戻ってくるステップ数の最大公約数が 1 より大きい場合、その状態は**周期的**であるといいます。  
すべての状態が周期 1 なら**非周期的（aperiodic）**です。  
強化学習でよく使われる「十分にランダムな探索」を行うと、実質的に非周期的とみなせるケースが多いです。

__4.3 定常分布（stationary distribution）__

遷移を繰り返すうちに、状態分布が時間によらず一定になることがあります。その分布を**定常分布** $${ \pi(s) }$$ と呼び、次の式を満たします。
$${ \pi(s') = \sum_{s \in S} \pi(s) P(s' \mid s) }$$
既約で非周期な有限状態マルコフチェインは、必ず一意の定常分布に収束します。

### 5. 強化学習との関係

強化学習では、エージェントが環境と相互作用しながら「行動」を選び、「報酬」を得て、「状態」が遷移していきます。この環境のダイナミクスをモデル化する際に、マルコフチェインが基礎となります。

__5.1 マルコフ決定過程（MDP）__

強化学習の標準的な枠組みである**マルコフ決定過程（Markov Decision Process, MDP）**は、マルコフチェインに「行動」と「報酬」を加えたものです。

- 状態 $${ s \in S }$$
- 行動 $${ a \in A }$$
- 遷移確率 $${ P(s' \mid s, a) }$$
- 報酬 $${ r(s, a, s') }$$

ここで、**遷移確率がマルコフ性を持つ**ことが重要です。  
すなわち、
$${ \Pr(S_{t+1} = s' \mid S_t = s, A_t = a, S_{t-1}, A_{t-1}, \dots) = P(s' \mid s, a) }$$
と仮定します。これにより、価値関数や方策の理論がシンプルに構築できます。

__5.2 価値関数とベルマン方程式__

MDP における状態価値関数 $${ V^\pi(s) }$$ は、方策 $${ \pi }$$ に従って行動したときの期待累積報酬です。  
マルコフ性があるおかげで、次のような**ベルマン方程式**が成り立ちます。
$${ V^\pi(s) = \sum_{a} \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \big[ r(s, a, s') + \gamma V^\pi(s') \big] }$$
ここで $${ \gamma }$$ は割引率です。  
マルコフ性がないと、このような再帰的な関係は成り立たず、理論が非常に複雑になります。

__5.3 方策改善・価値反復__

マルコフ性とベルマン方程式があるからこそ、次のようなアルゴリズムが成り立ちます。

- **価値反復（Value Iteration）**  
  ベルマン最適方程式に基づき、価値関数を反復更新して最適方策を求める
- **方策反復（Policy Iteration）**  
  方策評価と方策改善を交互に繰り返す

いずれも「次の状態の分布が現在の状態と行動だけに依存する」というマルコフ性を前提としています。

## MDPの登場

マルコフチェインからマルコフ決定過程（MDP）への流れを、順を追って説明します。

**MDP** は **Markov Decision Process（マルコフ決定過程）** の略です。

強化学習において、**エージェントが行動を選び、その結果として状態が遷移し、報酬が得られる環境**を数学的にモデル化した枠組みです。

主な要素は：
- 状態（State）
- 行動（Action）
- 遷移確率（Transition probability）
- 報酬（Reward）
- 割引率（Discount factor）

MDP では「次の状態と報酬が、現在の状態と行動だけに依存する（マルコフ性）」と仮定することで、価値関数やQ学習などの理論・アルゴリズムが成り立ちます。

### 1. マルコフチェインの復習

マルコフチェイン（Markov chain）は、次のような性質を持つ確率過程です。

- 状態空間 $${ S }$$（例：天気の「晴れ」「雨」など）
- 遷移確率 $${ P(s' \mid s) }$$：状態 $${ s }$$ から $${ s' }$$ へ移る確率
- **マルコフ性**：次の状態の確率分布が、現在の状態だけに依存し、過去の履歴には依存しない

数式的には、
$${ \Pr(S_{t+1} = s' \mid S_t = s, S_{t-1}, \dots) = P(s' \mid s) }$$
が成り立ちます。

強化学習では、**環境の状態遷移がマルコフ性を持つ**と仮定することで、理論がシンプルになります。

### 2. マルコフチェインからマルコフ決定過程（MDP）へ

マルコフチェインは「状態が自律的に遷移する」モデルですが、強化学習では**エージェントが行動を選び、その結果として状態が遷移し、報酬が得られる**という構造が必要です。

そこで、マルコフチェインに次の要素を加えたものが**マルコフ決定過程（Markov Decision Process, MDP）** です。

- **行動（action）**：エージェントが選べる操作
- **報酬（reward）**：状態遷移や行動の結果として得られるスカラー値
- **方策（policy）**：状態から行動への確率的なマッピング

つまり、MDP は「**行動を伴うマルコフチェイン＋報酬**」と見なせます。

### 3. MDP の形式的な定義

MDP は通常、次の5つ組で定義されます。

1. **状態空間** $${ S }$$  
   環境が取りうる状態の集合。

2. **行動空間** $${ A }$$  
   エージェントが取りうる行動の集合。

3. **遷移確率** $${ P(s' \mid s, a) }$$  
   状態 $${ s }$$ で行動 $${ a }$$ をとったとき、次状態が $${ s' }$$ になる確率。  
   マルコフ性により、
   $${ \Pr(S_{t+1} = s' \mid S_t = s, A_t = a, S_{t-1}, A_{t-1}, \dots) = P(s' \mid s, a) }$$
   と仮定します。

4. **報酬関数** $${ r(s, a, s') }$$  
   状態 $${ s }$$ で行動 $${ a }$$ をとり、次状態 $${ s' }$$ に遷移したときに得られる報酬。  
   期待報酬 $${ R(s, a) = \mathbb{E}[r(s, a, S')] }$$ と書くこともあります。

5. **割引率** $${ \gamma \in [0, 1] }$$  
   将来の報酬を現在価値に換算するための割引率。

これに加えて、エージェントの**方策（policy）** $${ \pi(a \mid s) }$$ が与えられると、MDP 上の確率過程が完全に決まります。

### 4. MDP におけるマルコフ性

MDP の重要な仮定は、**遷移確率と報酬がマルコフ性を持つ**ことです。

- 遷移：$${ P(s' \mid s, a) }$$ は、過去の状態・行動の履歴に依存しない
- 報酬：$${ r(s, a, s') }$$ も同様に、現在の $${ s, a, s' }$$ だけで決まる

この仮定により、
- 状態価値関数 $${ V^\pi(s) }$$
- 行動価値関数 $${ Q^\pi(s, a) }$$

が**ベルマン方程式**というシンプルな再帰関係を満たし、動的計画法やTD学習などのアルゴリズムが成り立ちます。

### 5. MDP における価値関数

__5.1 状態価値関数 $${ V^\pi(s) }$$__

方策 $${ \pi }$$ に従って行動するときの、状態 $${ s }$$ からの**期待累積割引報酬**です。
$${ V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s \right] }$$

マルコフ性とベルマン方程式により、
$${ V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} P(s' \mid s, a) \Big[ r(s, a, s') + \gamma V^\pi(s') \Big] }$$
が成り立ちます。

__5.2 行動価値関数 $${ Q^\pi(s, a) }$$__

状態 $${ s }$$ で行動 $${ a }$$ をとり、その後は方策 $${ \pi }$$ に従うときの期待累積割引報酬です。
$${ Q^\pi(s, a) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s, A_t = a \right] }$$

ベルマン方程式は、
$${ Q^\pi(s, a) = \sum_{s'} P(s' \mid s, a) \sum_{a'} \pi(a' \mid s') \Big[ r(s, a, s') + \gamma Q^\pi(s', a') \Big] }$$
となります。

### 6. 最適制御とベルマン最適方程式

MDP の目標は、**期待累積報酬を最大化する方策 $${ \pi^* }$$** を見つけることです。

最適状態価値関数 $${ V^*(s) }$$ と最適行動価値関数 $${ Q^*(s, a) }$$ は、
$${ V^*(s) = \max_\pi V^\pi(s), \quad Q^*(s, a) = \max_\pi Q^\pi(s, a) }$$
で定義されます。

これらは**ベルマン最適方程式**を満たします。

- 状態価値版：
  $${ V^*(s) = \max_a \sum_{s'} P(s' \mid s, a) \Big[ r(s, a, s') + \gamma V^*(s') \Big] }$$
- 行動価値版：
  $${ Q^*(s, a) = \sum_{s'} P(s' \mid s, a) \Big[ r(s, a, s') + \gamma \max_{a'} Q^*(s', a') \Big] }$$

この方程式から、価値反復（Value Iteration）や方策反復（Policy Iteration）、Q学習などのアルゴリズムが導かれます。

### 7. マルコフチェインとの関係のまとめ

- **マルコフチェイン**：  
  状態が自律的に遷移する確率過程。遷移確率 $${ P(s' \mid s) }$$ とマルコフ性が中心。

- **マルコフ決定過程（MDP）**：  
  マルコフチェインに
  - 行動 $${ a }$$
  - 報酬 $${ r(s, a, s') }$$
  - 方策 $${ \pi(a \mid s) }$$
  を加えたもの。  
  遷移確率は $${ P(s' \mid s, a) }$$ となり、「行動を選ぶことで状態遷移を制御できるマルコフチェイン」と見なせる。

- マルコフ性があるからこそ、
  - 価値関数がベルマン方程式を満たす
  - 動的計画法やTD学習などの効率的なアルゴリズムが成り立つ

### 8. 具体例で見る違い

__8.1 マルコフチェインの例：天気モデル__

- 状態：晴れ、雨
- 遷移確率：晴れ→晴れ 0.7、晴れ→雨 0.3、雨→晴れ 0.4、雨→雨 0.6

ここには「行動」も「報酬」もありません。単に天気が確率的に遷移するだけです。

__8.2 MDP の例：簡単なグリッドワールド__

- 状態：グリッド上のマス
- 行動：上・下・左・右
- 遷移確率：行動どおりに動く確率 0.8、それ以外の方向にランダムに動く確率 0.2
- 報酬：ゴールマスに着くと +1、それ以外は 0

エージェントは行動を選び、その結果として状態が遷移し、報酬が得られます。これが MDP です。

## 行動価値関数の導出

マルコフチェイン（より正確にはマルコフ決定過程, MDP）から、強化学習で用いられる**行動価値関数の更新式**を導出します。

### 1. 前提：マルコフ決定過程（MDP）と行動価値関数

強化学習の標準的な枠組みは**マルコフ決定過程（Markov Decision Process, MDP）** です。

- 状態空間：$${ S }$$
- 行動空間：$${ A }$$
- 遷移確率：$${ P(s' \mid s, a) }$$
- 報酬：$${ r(s, a, s') }$$
- 割引率：$${ \gamma \in [0, 1] }$$

ここで重要なのは、**遷移確率がマルコフ性を持つ**ことです。
$${ \Pr(S_{t+1} = s' \mid S_t = s, A_t = a, S_{t-1}, A_{t-1}, \dots) = P(s' \mid s, a) }$$

**行動価値関数（Q関数）** $${ Q^\pi(s, a) }$$ は、状態 $${ s }$$ で行動 $${ a }$$ をとり、その後は方策 $${ \pi }$$ に従って行動したときの**期待累積割引報酬**です。
$${ Q^\pi(s, a) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s, A_t = a \right] }$$

### 2. ベルマン方程式（行動価値版）

MDP とマルコフ性から、行動価値関数に対する**ベルマン方程式**が導かれます。

時刻 $${ t }$$ から見た累積報酬を分解すると、
$${ \sum_{k=0}^\infty \gamma^k R_{t+k+1} = R_{t+1} + \gamma \sum_{k=0}^\infty \gamma^k R_{t+k+2} }$$
です。

期待値をとると、
$${ Q^\pi(s, a) = \mathbb{E}_\pi \left[ R_{t+1} + \gamma Q^\pi(S_{t+1}, A_{t+1}) \;\middle|\; S_t = s, A_t = a \right] }$$

遷移と方策に分解すると、
$${ Q^\pi(s, a) = \sum_{s'} P(s' \mid s, a) \sum_{a'} \pi(a' \mid s') \Big[ r(s, a, s') + \gamma Q^\pi(s', a') \Big] }$$

これが**行動価値関数に対するベルマン方程式**です。

### 3. 最適行動価値関数とベルマン最適方程式

最適方策 $${ \pi^* }$$ に対応する**最適行動価値関数** $${ Q^*(s, a) }$$ は、
$${ Q^*(s, a) = \max_\pi Q^\pi(s, a) }$$
で定義されます。

最適方策の下では、次の状態 $${ s' }$$ で**最適な行動**をとるので、
$${ Q^*(s, a) = \sum_{s'} P(s' \mid s, a) \Big[ r(s, a, s') + \gamma \max_{a'} Q^*(s', a') \Big] }$$
が成り立ちます。これが**ベルマン最適方程式**です。

### 4. 行動価値関数の更新式の導出（Q学習）

__4.1 ベルマン最適方程式を「目標値」とみなす__

ベルマン最適方程式の右辺を「真の値に近い目標値」とみなします。
$${ \text{target}(s, a) = \sum_{s'} P(s' \mid s, a) \Big[ r(s, a, s') + \gamma \max_{a'} Q^*(s', a') \Big] }$$
実際には遷移確率 $${ P }$$ は未知であることが多いので、**サンプル** $${ (s, a, r, s') }$$ を使って近似します。

サンプルから得られる**1ステップの目標値**は、
$${ \text{target}_\text{sample} = r + \gamma \max_{a'} Q(s', a') }$$
です（ここで $${ Q }$$ は現在の推定値）。

__4.2 現在の推定値を目標値に近づける__

現在の推定値 $${ Q(s, a) }$$ を、サンプル目標値に少しだけ近づける更新を考えます。
$${ Q_\text{new}(s, a) = Q(s, a) + \alpha \Big[ \text{target}_\text{sample} - Q(s, a) \Big] }$$
ここで $${ \alpha \in (0, 1] }$$ は**学習率**です。

代入すると、
$${ Q(s, a) \leftarrow Q(s, a) + \alpha \Big[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \Big] }$$
これが**Q学習（Q-learning）の更新式**です。

- 右辺第2項は「**TD誤差（temporal difference error）** 」と呼ばれます。
- マルコフ性（遷移が $${ s, a }$$ だけに依存）があるからこそ、このような単純な更新式で理論的に最適解に収束することが保証されます（適切な条件下で）。

### 5. 方策オン型アルゴリズム（SARSA）の更新式

Q学習は**オフポリシー**（行動方策と評価方策が異なりうる）ですが、**オンポリシー**の代表例として **SARSA** があります。

SARSA では、次の行動 $${ a' }$$ も実際に方策 $${ \pi }$$ からサンプリングして使います。

ベルマン方程式
$${ Q^\pi(s, a) = \mathbb{E}_\pi \Big[ R_{t+1} + \gamma Q^\pi(S_{t+1}, A_{t+1}) \mid S_t = s, A_t = a \Big] }$$
をサンプル近似すると、
$${ \text{target}_\text{sample} = r + \gamma Q(s', a') }$$
となります。

これを用いて同様に更新すると、
$${ Q(s, a) \leftarrow Q(s, a) + \alpha \Big[ r + \gamma Q(s', a') - Q(s, a) \Big] }$$
が**SARSA の更新式**です。

- Q学習との違いは、$${ \max_{a'} Q(s', a') }$$ か $${ Q(s', a') }$$ かという点だけです。
- これもマルコフ性を前提としたベルマン方程式から自然に導かれます。

### 6. 一般化：nステップTDや期待SARSA

ベルマン方程式を**nステップ**に拡張すると、nステップTD法やnステップQ学習などが導かれます。また、

$${ Q(s, a) \leftarrow Q(s, a) + \alpha \Big[ r + \gamma \mathbb{E}_{a'\sim\pi(\cdot|s')} Q(s', a') - Q(s, a) \Big] }$$
という形の**期待SARSA（Expected SARSA）**も、ベルマン期待方程式から自然に導出されます。

### 7. 全体像

- マルコフ決定過程（MDP）とマルコフ性から、**行動価値関数に対するベルマン方程式**が導かれる。
- ベルマン方程式の右辺を「目標値」とみなし、サンプルで近似して**TD誤差**を計算し、現在のQ値をそれに近づける形で更新式を導く。
- 具体的には、
  - **Q学習**：$${ Q(s, a) \leftarrow Q(s, a) + \alpha \big[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \big] }$$
  - **SARSA**：$${ Q(s, a) \leftarrow Q(s, a) + \alpha \big[ r + \gamma Q(s', a') - Q(s, a) \big] }$$
- いずれも、マルコフ性があるからこそ「次の状態・報酬が現在の状態と行動だけで決まる」と仮定でき、シンプルな更新式で理論的な収束が保証される。


## 総括
本日の総まとめです。

1. **環境の状態遷移をマルコフチェインとしてモデル化**する（マルコフ性）。
2. そこに**行動と報酬を加えて MDP** とする。
3. MDP 上で**価値関数（特に行動価値関数 Q）**を定義し、ベルマン方程式で表現する。
4. ベルマン方程式から**TD誤差を使った更新式（Q学習など）**を導き、Q値を反復更新する。
5. Q値が収束すれば、**最適方策 $${ \arg\max_a Q(s, a) }$$** が得られる。

この流れが、強化学習の理論的な「骨組み」になっています。  
この先は、関数近似（深層Qネットワークなど）、方策勾配法、マルチエージェント強化学習などに発展していきますが、その土台はここまでの MDP と Q関数の考え方です。
